# Test Repository

This repository is for experimenting with GitHub and ChatGPT integration.

## Forma Supply demo storefront

A responsive, front-end-only ecommerce demo built with HTML, CSS, and vanilla JavaScript.

### Run locally

1. Clone the repository or download the files from the `feature/ecommerce-store` branch.
2. Open `index.html` in a browser. For the best local development experience, serve the folder with a simple static web server.

### Features

- Responsive storefront layout
- Fictional product catalogue with category filters, search, and sorting
- Shopping bag with quantity controls and subtotal
- Demo newsletter interaction
- Demo checkout notice (no payments or orders are processed)

Product photography and web fonts load from external services, so an internet connection is needed for those assets.

**Demo only:** The store does not have a backend, inventory, account system, or payment processing. Newsletter addresses are not saved.
